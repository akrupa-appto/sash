approvals and site access

the two choices below save with the rest of your settings, using the save button at the bottom. everything under them is live: revoking takes effect immediately, and revoking does not undo an action already taken.

action approvals

when checkto has to stop and ask before doing something. the first choice prompts a lot on purpose — you see every action before it happens.

site access

whether Chrome lets checkto reach a site at all. this is Chrome's access to a site, not individual actions — the choice above covers those.

saved approvals

actions allowed for this conversation or always. revoking asks you again next time; it does not cancel an action already approved.

sites Chrome has allowed

every site Chrome currently lets checkto reach. access marked required comes with the extension itself: Chrome only lets you narrow it (to specific sites, or on click) from checkto's page in chrome://extensions, not from here. anything else can be revoked below; that stops the current task first, and removing a custom provider's site disconnects that provider until you allow it again.

removing site access does not remove a saved approval, or vice versa.
